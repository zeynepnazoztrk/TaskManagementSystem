![Dashboard](./AppScreen/DashboardPage.png)

The tasks page contains the list of tasks and the add and filtering options.
![Tasks Page](./AppScreen/TasksPage.png)

### 9. The "Add Task" button opens the related form.
![Tasks Page Add Task](./AppScreen/TasksPage_AddTask.png)
